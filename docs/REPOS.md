# Upstream Repositories

This plugin is a local packaging layer around upstream projects.

## Google Search Console MCP

- Repository: https://github.com/ncosentino/google-search-console-mcp
- Role: MCP server for Search Console API access
- Auth: service account JSON
- Status: community project, not official Google

## Google Analytics MCP

- Repository: https://github.com/googleanalytics/google-analytics-mcp
- Role: MCP server for GA4 Data and Admin API access
- Auth: Google Application Default Credentials or OAuth JSON
- Status: experimental Google Analytics project

## CrUX

- API: https://developer.chrome.com/docs/crux/api/
- Role: field UX metrics by origin or URL
- Auth: optional API key depending on quota and environment
